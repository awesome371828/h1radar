Обработка данных

H1 RADAR — гражданская информационная платформа с авторизацией через Telegram. Эта политика описывает данные, которые нужны для создания аккаунта и работы функций сайта.

Какие данные обрабатываются

При входе Telegram передаёт приложению Telegram ID, имя и username (если он указан). Проект создаёт случайный публичный код пользователя RU-XXXX. Номер телефона не запрашивается и не требуется для входа.

При отправке сообщения сохраняются выбранный город, категория, текст, дата создания и статус проверки. Для входа создаётся случайный одноразовый токен, а в базе хранится его криптографический хеш и срок действия сессии.

Цели и доступ

Данные используются для создания профиля, защиты входа, обработки обращений и модерации публикаций. Доступ к данным аккаунтов ограничен владельцем и назначенными модераторами в объёме, необходимом для их работы.

Хранение и удаление

Данные хранятся в базе данных проекта. Пользователь может удалить аккаунт из профиля на карте. При удалении удаляются аккаунт и связанные с ним сессии; опубликованные сообщения сохраняются без привязки к автору, если это требуется для целостности публичной ленты.

Безопасность

Ссылки входа одноразовые и действуют ограниченное время. Сессионные токены хранятся в базе в виде SHA-256 хеша. Передача данных осуществляется по HTTPS. Не отправляйте в сообщения пароли, платёжные реквизиты, документы или чувствительные координаты.

Важное ограничение

H1 RADAR — гражданский информационный проект, а не официальный источник экстренных оповещений. Публикации пользователей проходят модерацию и могут содержать ошибки.
